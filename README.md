# ALTA RUNA – тестовый сайт

Публикация: https://jousille.github.io/alta-runa-test/

Исходник: https://github.com/jousille/altaruna (ветка alta-runa-test).

Это публичная тестовая копия. `scripts/build.mjs` собирает страницы, а GitHub Actions публикует их через Pages. Индексация поисковиками отключена. Здесь не должен размещаться производственный CNAME `altaruna.ru`.

Настройка: Settings → Pages → Build and deployment → Source → GitHub Actions.
